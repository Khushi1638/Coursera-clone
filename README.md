# Coursera Clone - Web Page

This is a simple Coursera homepage clone built using HTML and CSS. It is a static web page created for front-end development practice. The project aims to replicate the layout and design of the Coursera landing page while also applying responsive design techniques.

## Features

* Static clone of Coursera's homepage
* Implemented responsive layout for desktop and tablet/mobile view
* Clean and structured code using semantic HTML and modern CSS

## Current Limitations

* **Menu bar responsiveness**: The responsive menu bar for tablet and mobile view is not yet implemented. This will be the next feature to be added.
* **Dark mode**: A dark mode toggle will be added in a future update to enhance user experience.

## Technologies Used

* HTML
* CSS (including media queries for responsiveness)

## Future Goals

* Complete the responsive menu bar for smaller screens
* Implement a dark mode feature

## Getting Started

To view the project:

1. Clone the repository:

```bash
git clone <repo-url>
```

2. Open the `index.html` file in your browser.
